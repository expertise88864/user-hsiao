📋 編輯流程

  1. 點「編輯」開啟文章 — 整篇變成所見即所得 (WYSIWYG) 模式
  2. 滑鼠選文字後出現浮動工具列：粗體 / 斜體 / 標題 / 字型 / 字級 / 連結 / 列表
  3. 按右下「儲存」→ 自動 commit 到 GitHub → Vercel 自動重新部署
  4. 若你之後在本機改檔案，記得先 git pull 把後台的編輯拉下來
