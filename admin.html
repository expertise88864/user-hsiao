文章管理

📋 編輯流程

  1. 點「編輯」開啟文章 — 整篇變成所見即所得 (WYSIWYG) 模式
  2. 滑鼠選文字後出現浮動工具列：粗體 / 斜體 / 標題 / 字型 / 字級 / 連結 / 列表 / 📷 圖片
  3. 按右下「儲存」→ 自動 commit 到 GitHub → Vercel 自動重新部署 (~30 秒）
  4. 若你之後在本機改檔案，記得先 git pull 把後台的編輯拉下來
  5. 「📚 歷史」可查看過往 commit、回滾到任一版本
  6. 「🌐 EN」會把這篇文章重新生成 /en/ 鏡像

A/B 測試結果

📊 A/B 框架使用方法

在 JS 內用 DN.abTest('test-id', ['A', 'B'], v => {...}) 並 DN.abConvert('test-id', 'click') 觸發轉換。Server 端聚合會在每 5 分鐘或每 10 次曝光時 commit 一次到 assets/ab-stats.json。
尚無資料

A/B Builder

🧪 不用改 JS 的 A/B 測試

填一個 CSS selector + 兩個 variant 的 HTML, 後台儲存到 KV （或 GitHub blob), 客戶端 DN.applyAbConfig() 自動套用。曝光與轉換寫進 /api/admin/ab-stats, 結果在「📈 A/B 結果」分頁看。
尚無測試

新 A/B 測試

變體會直接 innerHTML 替換目標元素。不能含 <script> 或 on*= 事件。

需先在 Vercel 設 GA4_PROPERTY_ID + GA4_SERVICE_ACCOUNT_JSON(GCP service account JSON 字串）。
點「🔄 重新載入」開始

CSP 違規回報

🛡️ 瀏覽器回報的 Content-Security-Policy 違規

每個 CSP 違規會 POST 到 /api/csp-report，存最近 200 筆於 KV。下方依違規類型、被擋來源、發生檔案彙整。
點「🔄 重新載入」開始

瀏覽器端 JS 錯誤

🐛 unhandled error / rejection 自動回報

DN.bindErrorReporting() 把全域 error + unhandledrejection POST 到 /api/errors，存最近 200 筆於 KV。下方依錯誤類型、訊息開頭、發生頁面彙整。
點「🔄 重新載入」開始

站內搜尋查詢

🔎 患者在 Cmd+K 搜了什麼

Cmd+K 輸入 ≥ 2 字會 POST 到 /api/search-log，僅當 Vercel 設 SEARCH_LOG_ENABLED=1 時才存。只記查詢字串 + 時間：不存 IP、不存 UA、不存 cookie。cap 1000 筆滾動。用來找出「患者在搜但站上沒文章」的主題。
點「🔄 重新載入」開始

站務 / 維運

🌐 重新生成 /en/ 鏡像

中文文章編輯後，英文鏡像不會自動同步。點此重新生成所有 /en/ 頁面 （約 30-60 秒）。

🛡️ Service Worker

清除瀏覽器端 SW 快取，重新註冊。除錯時用。

🚿 Edge cache purge

清空 Vercel CDN 快取，讓動態 sitemap / feed 立即更新（不用等 s-maxage）。需設 VERCEL_TOKEN。

🤖 重建相關文章 ML

用 TF-IDF + 醫學詞典加權重新計算每篇文章的相關推薦，寫到 assets/related.json。

📊 Pre-compute 字數 + 閱讀時間

把每篇文章字數與閱讀分鐘數寫進 DN.ARTICLES，客戶端不用 runtime 計算。

⚡ 批次運行

對所有文章跑 SEO 修復 + FAQ schema + 醫學詞典 auto-link, 一鍵 done。

📢 發送 Web Push 通知

所有訂閱者會收到加密推播 (aes128gcm)。需先設好 VAPID env vars。

🛠️ 動態 Sitemap / Feed

已從 DN.ARTICLES 動態產生。手動觸發 CDN 失效以立即更新。

看 sitemap.xml 看 RSS 看 Atom
