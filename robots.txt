# ========== AI policy (v34.15) ==========
# Two tiers:
#   1. ALLOWED: query-time agents that fetch a URL on behalf of a user
#      asking a question and cite the source. These bring real readers
#      back via "answer + source link" surfaces:
#        - ChatGPT-User    (ChatGPT browsing / Search citations)
#        - PerplexityBot   (Perplexity answer citations)
#        - ClaudeBot       (Claude.ai web tool, citation-aware)
#        - Google-Extended (Google AI Overview / Gemini citations)
#      These have explicit groups above so the policy is easy to audit.
#   2. DISALLOWED: bulk training crawlers and aggregators with no
#      reciprocal traffic, plus low-quality scrapers.
# ========================================
