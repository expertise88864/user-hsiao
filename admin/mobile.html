使用 GitHub Personal Access Token 登入。Token 只存在你的瀏覽器 localStorage，不會傳到任何第三方伺服器。

還沒有 Token？到 GitHub 設定頁 建立一個 Fine-grained personal access token，限制： Repository = user-hsiao， Permissions = Contents: Read and write。
