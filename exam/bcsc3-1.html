第 257 題BCSC 3 · Ch.3BCSC 3 · Ch.1

某一無水晶體（aphakia）的眼球，假設角膜的屈光力（refractive power）為44.0D 而空氣的折射係數（refractive index）為1.0，眼球內的折射係數為1.33，請問遠處物體會成像在角膜後方多少公釐（mm）處？

第 257 題選項

答案：C依 BCSC 判斷

以單一折射面計算，像距 = n/P = 1.33/44 D ≈ 0.0302 m，即角膜後約 30.2 mm。

  • A錯誤若成像於 26.2 mm，角膜屈光力需約 1.33/0.0262 ≈ 50.8 D，與題目 44 D 不符。BCSC 3 p.67
  • B錯誤28.2 mm 對應約 47.2 D 的屈光面；以 44 D 計算，像距應更遠。BCSC 3 p.67
  • C正確依 vergence equation（聚散度方程式）U + P = V，遠物 U = 0，故 1.33/v = 44，v ≈ 30.2 mm；aphakia（無水晶體）眼的焦點遠在約 24 mm 的視網膜之後，呈高度遠視。BCSC 3 p.67；BCSC 3 p.78；BCSC 3 p.146；BCSC 3 p.157
  • D錯誤32.2 mm 需屈光力約 1.33/0.0322 ≈ 41.3 D，低於題目給的 44 D。BCSC 3 p.67

考點：Chromatic aberration（色差）3 題

第 204 題BCSC 3 · Ch.1BCSC 3 · Ch.4

關於chromatic aberration 下列敘述何者不正確？

第 204 題選項

答案：C依 BCSC 判斷

眼睛對藍光較近視，看藍字所需的 accommodation 反而較少，故 C 敘述錯誤。

  • A敘述正確Chromatic aberration（色像差）源自 dispersion（色散）：凸透鏡對藍光的聚焦點在紅光之前，BCSC 指出眼睛對藍光約比紅光近視 0.50 D，duochrome 濾片的紅綠間距也約 0.50 D。BCSC 3 p.92；BCSC 3 p.179
  • B敘述正確紅光聚焦在藍光之後（相對遠視），眼睛須多用 accommodation（調節）才能看清紅色物體，大腦把較大的調節量解讀為距離較近，因此紅色物體常顯得較近。BCSC 未直接描述此知覺現象，屬依色差原理推論。BCSC 3 p.92
  • C敘述錯誤藍光聚焦在視網膜前方，眼睛對藍色目標相對近視，看藍字所需的 accommodation（調節）比看紅字少，而非較多，故此敘述錯誤。BCSC 3 p.92；BCSC 3 p.179
  • D敘述正確Duochrome test（紅綠測試）中綠字較清楚代表矯正偏負（over-minus），應加正度數（green add plus）；遠視者戴正鏡片出現綠字較清楚，表示正度數不足。BCSC 3 p.179–180

⚠ A 選項依 BCSC 所述紅藍光約差 0.50 D 判為正確；若以整個可見光譜計算，人眼縱向色差約 2 D，題意可能有爭議。

⚠ B 選項（紅色物體看起來較近，即 chromostereopsis）BCSC 未直接討論，依色差與調節推論。

第 269 題BCSC 3 · Ch.1BCSC 3 · Ch.5BCSC 3 · Ch.4

下列何者和色相差（chromatic aberration）最不相關？

第 269 題選項

答案：C依 BCSC 判斷

Astigmatism 是單色像差，與波長造成的色像差無直接關係。

  • A相關Abbe number（阿貝數）描述折射率隨波長的變化，數值越低色像差越大，是衡量 chromatic aberration（色像差）的指標。BCSC 3 p.213
  • B相關Chromatic aberration（色像差）源自 dispersion（色散），即折射率隨 wavelength（波長）改變，藍光比紅光折射更強。BCSC 3 p.92；BCSC 3 p.58–59
  • C不相關Astigmatism（散光）屬於單色像差，源自不同子午線屈光力不同，與光的波長無關；BCSC 將其與色像差分開討論。BCSC 3 p.92
  • D相關Duochrome test（紅綠測試）正是利用眼睛的 chromatic aberration（色像差），紅綠波長焦點相差約 0.50 D。BCSC 3 p.179–180；BCSC 3 p.92

第 270 題BCSC 3 · Ch.1BCSC 3 · Ch.3BCSC 3 · Ch.2

下列何者和夜間近視（night myopia）最不相關？

第 270 題選項

答案：C依 BCSC 判斷

Night myopia 與瞳孔放大、正向 spherical aberration 有關，與 constructive interference 無關。

  • A相關暗處 pupil size（瞳孔大小）變大，周邊光線參與成像，使 spherical aberration（球面像差）的影響增加。BCSC 3 p.91
  • B相關Positive spherical aberration（正球面像差）使周邊光線聚焦在前，瞳孔放大時最佳焦點前移而變得較近視，即 night myopia（夜間近視）。屈光手術後正球面像差增加也是夜間近視主因。BCSC 3 p.91；BCSC 3 p.293
  • C不相關Constructive interference（建設性干涉）屬於波動光學現象，應用於如干涉濾光片，與夜間近視的機制無關。BCSC 3 p.122–124
  • D相關BCSC 建議以夜間使用、額外加 −0.50 D 的眼鏡處理 night myopia（夜間近視），與「低亮度下近視增加約 50 度」相符。BCSC 3 p.91

第 216 題BCSC 3 · Ch.1BCSC 3 · Ch.7

已知1 個人工水晶體（intraocular lens）的折射係數（refractive index）為1.492，其在房水（aqueous humor）中之屈光度數為20D (diopter)，則這個水晶體在空氣中為多少屈光度數？

第 216 題選項

答案：C依 BCSC 判斷

薄透鏡屈光力與（鏡片折射率 − 周圍介質折射率）成正比：20 × 0.492/0.156 ≈ 63 D。

  • A錯誤依 lensmaker's equation（造鏡者公式），屈光力正比於鏡片與介質的折射率差；空氣中為 20 × (1.492−1)/(1.492−1.336) ≈ 63 D，43 D 低估。BCSC 3 p.68
  • B錯誤Lensmaker's equation（造鏡者公式）換算得約 63 D，而非 53 D。BCSC 3 p.68
  • C正確Intraocular lens（IOL，人工水晶體）曲率不變，屈光力與 (n鏡片 − n介質） 成正比：房水中差值 0.156、空氣中 0.492，故空氣中度數 ≈ 20 × 0.492/0.156 ≈ 63 D，與 BCSC 所述 IOL 在空氣中約為標示度數 3 倍一致。BCSC 3 p.68
  • D錯誤依 lensmaker's equation（造鏡者公式）計算約 63 D，73 D 高估。BCSC 3 p.68

考點：橫向與縱向放大率3 題

第 218 題BCSC 3 · Ch.1

一個物體高度（垂直光軸perpendicular to the optical axis）為4cm，長度（平行光軸along the optical axis）為0.5cm，而這個物體transverse magnification 為2 倍（2×)，axial magnification 為4 倍（4×)，則這個物體像高及像長，最可能是下列何者？

第 218 題選項

答案：A依 BCSC 判斷

  • A錯誤依 Pθ = PS + PC sin²(θ − φ)，兩鏡片柱鏡在 180° 子午線的分量都是 −1.5 × sin²10°，差值等於球面差 2 D，不是 1 D。BCSC 3 p.97
  • B正確軸 170° 與 10° 都與 180° 子午線相差 10°，柱鏡分量相同（約 −0.05 D），故水平方向屈光力差 = −4 − (−2) = 2 D。BCSC 3 p.97
  • C錯誤柱鏡分量相互抵銷後只剩球面差 2 D，3 D 不正確。BCSC 3 p.97
  • D錯誤4 D 未依 sin² 公式計算，與實際差值 2 D 不符。BCSC 3 p.97

下列何者的組合最不具有相關性？

第 213 題選項

答案：A依 BCSC 判斷

抗反射膜利用的是 destructive interference，不是 diffraction。

第 238 題BCSC 3 · Ch.1

一物體位於一個+6.0D 的透鏡左側50 公分處，此透鏡左側為空氣，右側為水（空氣的折射率為1，水的折射率為1.33)，請問其成像最終落於何處？

第 238 題選項

答案：D依 BCSC 判斷

U = −2 D，V = U + P = +4 D；像在水中，v = n/V = 1.33/4 ≈ 0.33 m，即鏡後 33 cm。

  • A錯誤物距 50 cm 時 U = −2 D，加上 +6 D 得 V = +4 D（正值），為鏡後實像，不在空氣側。BCSC 3 p.67–68

  • C錯誤25 cm 是以空氣折射率計算 1/V 的結果；像在水中須用 reduced vergence（約化聚散度）V = n/v，v = 1.33/4 ≈ 33 cm。BCSC 3 p.67–68
  • D正確依 vergence equation（聚散度公式）n1/u + P = n2/v：−2 + 6 = +4 D = 1.33/v，v ≈ 0.33 m，成像於水中透鏡後約 33 cm。BCSC 3 p.67–68
第 255 題BCSC 3 · Ch.1BCSC 3 · Ch.5BCSC 3 · Ch.3

下列有關折射係數（refractive index）的敘述何者為非？

第 255 題選項

答案：A依 BCSC 判斷

水晶體折射率（1.386–1.406）高於角膜（1.376），光在水晶體中較慢，故 A 錯。

  • A敘述錯誤Refractive index（折射率）= 真空光速 / 介質光速，折射率越高光速越慢。Gullstrand 模型眼中角膜 1.376、水晶體 1.386–1.406，光在水晶體中較慢，故此敘述錯誤。BCSC 3 p.57；BCSC 3 p.145–147
  • B敘述正確光由較高折射率（角膜 1.376）進入較低折射率（房水 1.336）時，入射角超過 critical angle（臨界角）即會發生 total internal reflection（全反射），理論上可能發生。BCSC 3 p.64–65；BCSC 3 p.58
  • C敘述正確BCSC 指出鏡片材料折射率越高，Abbe number（阿貝數）通常越低，dispersion（色散）與色像差越明顯。BCSC 3 p.213–214
  • D敘述正確空氣（1.000）與角膜（1.376）之間的折射率差最大，是眼球屈光力的主要來源；角膜與房水之間的差則小得多。BCSC 3 p.58；BCSC 3 p.67–68

⚠ B 選項：角膜（1.376）到房水（1.336）由高折射率進入低折射率，物理上入射角超過約 76° 才會全反射，眼內實際幾何條件下難以發生；依「可能」字面判為正確。

第 260 題BCSC 3 · Ch.1

物體在鏡片+4.0-2.0 x 60 左側1 公尺，則最清晰呈像在鏡片右側？

第 260 題選項

答案：C依 BCSC 判斷

兩子午線 +4 D、+2 D 分別成像於 33 cm、100 cm；最小模糊圈在 SE +3 D：V = −1 + 3 = +2 D，即 50 cm。

  • A錯誤20 cm 不對應任何子午線：+4 D 子午線 V = +3 D（33 cm），+2 D 子午線 V = +1 D（100 cm）。BCSC 3 p.92–93
  • B錯誤33 cm 是 +4 D 子午線形成的焦線位置，只是 conoid of Sturm（Sturm 錐）的一端，不是最清晰的圓形像。BCSC 3 p.92–95
  • C正確Spherical equivalent（等效球面度）= +4 − 1 = +3 D；V = −1 + 3 = +2 D，circle of least confusion（最小模糊圈）在鏡後 50 cm，BCSC 以相同方法計算 COLC 位置。BCSC 3 p.94–95
  • D錯誤100 cm 是 +2 D 子午線的焦線位置，另一端焦線，不是 circle of least confusion（最小模糊圈）。BCSC 3 p.92–95

第 272 題BCSC 3 · Ch.1BCSC 3 · Ch.4

在一正視眼的病患眼前放置一交叉圓柱鏡的鏡片，白點位於水平方向，請問水平方向來的光線，下列敘述何者正確？

第 272 題選項

答案：D依 BCSC 判斷

白點為正柱鏡軸：白點水平使垂直子午線 +、水平子午線 −；水平子午線光線聚焦在網膜後，形成垂直焦線。

  • A錯誤Jackson cross cylinder（JCC，交叉圓柱鏡）白點代表正柱鏡軸；白點水平時，正度數作用在垂直子午線，負度數作用在水平子午線，水平子午線光線應聚焦在網膜後，而非前方。BCSC 3 p.177；BCSC 3 p.97–98
  • B錯誤聚焦在網膜前的是垂直子午線的光線（且形成水平焦線），不是水平子午線的光線。BCSC 3 p.177；BCSC 3 p.95
  • C錯誤水平子午線光線的確聚焦於網膜後，但其焦線方向應與產生它的柱鏡軸（垂直，紅點方向）平行，為垂直焦線而非水平焦線。BCSC 3 p.95；BCSC 3 p.92–93
  • D正確正視眼前放 JCC（交叉圓柱鏡），白點（正柱鏡軸）水平、紅點（負柱鏡軸）垂直：水平子午線帶負度數，光線聚焦在網膜後；光線經柱鏡會在其軸向形成線，故為垂直焦線。BCSC 3 p.177；BCSC 3 p.95；BCSC 3 p.97–98

⚠ 題目未說明「水平方向來的光線」是指水平子午線的光線，依此解讀作答；若解讀不同答案可能改變。
