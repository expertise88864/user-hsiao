一、概論、定義與分期

Angle closure（隅角閉鎖）的定義

  • Angle closure（隅角閉鎖）指周邊虹膜以機械方式阻塞 trabecular meshwork（TM，小樑網）的解剖型態；阻塞可經由 apposition（貼合，即 iridotrabecular contact，虹膜小樑網接觸）或 peripheral anterior synechiae（PAS，周邊前粘連；周邊虹膜黏附於 TM）形成⁠Q1229。p.151
  • 依病因分兩大類：primary angle closure（原發性）找不到續發病理狀況，只有解剖上的易感性；secondary angle closure（續發性）由可辨識的病理狀況啟動，例如 intumescent lens（膨脹水晶體）、虹膜新生血管、慢性發炎、角膜內皮移行進入隅角、epithelial ingrowth（上皮內生）（見 Chapter 10）⁠Q1229 Q1267 Q1739。p.151
  • 原發型是一個疾病光譜，可呈急性或慢性；primary angle-closure disease（PACD，原發性隅角閉鎖疾病）指前房隅角的貼合性或粘連性閉鎖。p.151–152
  • 臨床表現差異大：從急性隅角閉鎖的突發、劇烈發作，到慢性病的隱匿、無症狀表現；各型雖都有 PAS 或虹膜小樑網貼合，但造成這些特徵的機轉不同⁠Q1147 Q1192。p.152
  • 須辨識隅角的解剖變化與背後的病生理才能選對治療；多數型態的隅角閉鎖或狹窄若早期診斷與治療，有時可治癒。p.152

分期（Table 9-1）

Stage（分期）Definition（定義）
Primary angle-closure suspect（PACS，原發性隅角閉鎖疑似）Iridotrabecular contact ≥180°，但沒有 TM 或青光眼性視神經損傷的證據
Primary angle closure（PAC，原發性隅角閉鎖）Iridotrabecular contact ≥180°，合併統計上升高的 IOP 或 PAS，但沒有青光眼性視神經損傷
Primary angle-closure glaucoma（PACG，原發性隅角閉鎖青光眼）PAC 再加上 glaucomatous optic neuropathy（青光眼性視神經病變）

出處（Table 9-1）⁠Q1177p.152

  • PACS：眼睛的解剖型態增加發生隅角閉鎖疾病的風險；定義為狹窄隅角且 iridotrabecular contact ≥180°（常稱 occludable angle，可閉鎖隅角），沒有明顯 PAC 徵象（IOP 升高或 PAS）也沒有青光眼性視神經損傷⁠Q1177。p.152, p.157
  • PAC：TM 已有損傷或功能異常，表現為 PAS 或統計上升高的 intraocular pressure（IOP，眼壓）；第 161 頁寫為 iridotrabecular contact ≥180° 加上 PAS 及／或統計上升高的 IOP（>21 mm Hg）⁠Q1177。p.152, p.161
  • PACG：PAS 或統計上升高的 IOP（>21 mm Hg）再加上青光眼性視神經病變（視神經杯化、retinal nerve fiber layer（視網膜神經纖維層）流失，及／或符合青光眼的視野缺損）⁠Q1177。p.152

流行病學

  • 全球 angle-closure glaucoma（ACG，隅角閉鎖性青光眼）盛行人數估計 2020 年超過 2300 萬、2040 年超過 3200 萬。p.152
  • ACG 在女性及部分族群（如特定亞洲族群與 Inuit（因紐特人））較常見；歐洲與非洲族群盛行率一般低於亞洲族群，但基因異質性可使同一地區內的盛行率差異很大⁠Q1182 Q1203。p.152
  • 估計 ACG 佔華人族群青光眼致盲的 90% 以上。p.152
  • Highlights：PAC disease 是青光眼的常見原因，在亞洲族群尤其如此。p.151

易錯陷阱

  • PACS 與 PAC 的 iridotrabecular contact 門檻都是 ≥180°；兩者差在 PAC 已有統計上升高的 IOP 或 PAS⁠Q1177。p.152
  • PAC 與 PACG 差在是否已有青光眼性視神經病變（視神經杯化、RNFL 流失及／或視野缺損）⁠Q1177。p.152
  • Intumescent lens、虹膜新生血管、慢性發炎、角膜內皮移行、上皮內生屬續發性隅角閉鎖的啟動原因⁠Q1267 Q1739。p.151

二、致病機轉：Pupillary block 與 Plateau iris

總論

  • 隅角閉鎖的特徵是周邊虹膜貼合或黏附於 TM；受影響的隅角稱為「閉鎖」，房水經隅角引流因而減少，TM 外流減少使 IOP 上升。p.153
  • 閉鎖可為暫時、間歇性（appositional，貼合性）或永久性（synechial，粘連性）；兩者可用 dynamic gonioscopy（動態隅角鏡，又稱 compression 或 indentation gonioscopy）區分⁠Q1740。p.153
  • 除傳統機轉外，有人提出人眼正常的虹膜體積與含水量動態變化在 PACD 病人功能異常，可能在致病上扮演重要角色。p.153
  • 多種使瞳孔放大的因素 —— 某些藥物、疼痛、情緒激動、驚嚇等 —— 可能誘發急性隅角閉鎖。p.153
  • PACD 致病的主要機轉是 pupillary block（瞳孔阻滯）；但在最多三分之一的隅角閉鎖眼中，plateau iris（高原虹膜）是促成因素⁠Q1244 Q1193 Q1740。p.151, p.153

Pupillary block（瞳孔阻滯）

  • Pupillary block 是隅角閉鎖最常見（most frequent）的原因；PACD 的病生理複雜且未完全了解，但多數病例公認有 pupillary block 參與⁠Q1244 Q1740。p.153
  • 機轉：房水從後房經瞳孔流出時在 lens–iris interface（水晶體虹膜介面）受阻 → 前後房形成壓力差 → 周邊虹膜向前膨出貼向 TM（Fig 9-1A）⁠Q1244。p.153
  • 瞳孔在中度散大（mid-dilated）位置時 pupillary block 最大；多數隅角閉鎖的 pupillary block 來自 lens–iris interface 的解剖因素。p.153
  • 通暢的 peripheral iridectomy 或 iridotomy（周邊虹膜切除術／切開術）可解除 pupillary block⁠Q1151 Q1166 Q1263。p.153
  • LPI 適應症（Chapter 13）：懷疑 pupillary block 為虹膜小樑網接觸原因時施行；APAC、PAC、PACG 都可從 iridotomy 獲益，pupillary block 引起的續發性隅角閉鎖也可獲益；沒有 pupillary block 的隅角閉鎖（如 neovascular glaucoma、iridocorneal endothelial syndrome）iridotomy 無效，360° 粘連性隅角閉鎖的眼睛也無法從 iridotomy 獲益⁠Q1151 Q1166 Q1263 Q1740。BCSC 10 p.255
  • Chapter 10：aphakic／pseudophakic angle closure（無晶體／人工水晶體眼隅角閉鎖）也可能發生 pupillary block，可能需要一個或多個 LPI；phacomorphic glaucoma 可在白內障摘除前做 LPI 解除 pupillary block 成分⁠Q1151 Q1166 Q1263。BCSC 10 p.168, p.171
  • 有晶體眼中水晶體在 pupillary block 扮演關鍵角色：研究發現高 lens vault（水晶體拱高；水晶體突出於 scleral spur 平面前方的距離）是 PACD 的主要危險因子。p.153
  • 虹膜厚度、面積、體積也與較窄的隅角及隅角閉鎖風險強烈相關；較小的前房尺寸（前房深度、寬度、面積、體積）也是危險因子。p.153–154

Plateau iris 與 iris-induced angle closure（虹膜誘發隅角閉鎖）

  • 兩者都是周邊虹膜貼合於 TM。p.154
  • Iris-induced angle closure 可源於發育異常：anterior cleavage abnormalities（虹膜附著於 scleral spur 或 TM 的位置比正常靠前）、散瞳時會「捲入」TM 的厚周邊虹膜，及／或前移的 ciliary processes（睫狀突），可能繼而把周邊虹膜向前旋轉（plateau iris）頂入 TM（Fig 9-1B）⁠Q1739。p.154
  • Aniridia（無虹膜症）：過去認為殘存虹膜葉旋轉進入隅角而造成虹膜誘發隅角閉鎖，但證據提示此現象是眼內手術所致，而非自發。p.154
  • Ultrasound biomicroscopy（UBM，超音波生物顯微鏡）判讀隅角閉鎖從辨認 scleral spur 並判斷隅角擁擠程度開始；Fig 9-1A 為一隻 pupillary block 眼，可見虹膜前凸阻塞 TM；Fig 9-1B 為一隻 plateau iris 解剖的眼，可見大而前旋的睫狀突造成貼合性隅角閉鎖。p.154
  • Chapter 10 Table 10-1：非 pupillary block 隅角閉鎖分「拉扯」與「推擠」機轉；從後方推擠虹膜者包括 malignant glaucoma、serous 或 hemorrhagic uveal effusions（葡萄膜滲漏）、前位睫狀突（plateau iris configuration／syndrome）、anteriorly displaced lens（水晶體前移，如外傷、懸韌帶鬆弛）等；拉扯者包括發炎膜或纖維血管組織收縮、ICE syndrome 的異常角膜內皮移行等⁠Q1244 Q1739 Q1151。BCSC 10 p.168

易錯陷阱

  • PACD 的主要機轉是 pupillary block；plateau iris 是最多三分之一隅角閉鎖眼的促成因素⁠Q1244 Q1740。p.153
  • Pupillary block 在瞳孔中度散大時最大。p.153
  • Appositional 與 synechial closure 靠 dynamic（compression／indentation）gonioscopy 區分⁠Q1740。p.153
  • Lens vault 的定義是水晶體突出於 scleral spur 平面前方的距離；研究發現高 lens vault 是 PACD 主要危險因子。p.153

三、藥物與隅角閉鎖

  • 前房淺的易感眼，mydriatic（散瞳劑）或 miotic（縮瞳劑）都可能誘發急性隅角閉鎖；mydriatic agents 不只散瞳眼藥，也包括有 sympathomimetic（擬交感）或 anticholinergic（抗膽鹼）活性、可能使瞳孔輕度散大的全身藥物⁠Q1216 Q1167。p.154
  • 縮瞳劑的作用是把周邊虹膜拉離前房隅角；但強效縮瞳劑也可能使懸韌帶放鬆 → lens–iris interface 前移，並增加虹膜與水晶體接觸 → 可能加重 pupillary block；因此縮瞳劑（尤其 cholinesterase inhibitors，膽鹼酯酶抑制劑）可能誘發或加重隅角閉鎖。p.154
  • 隅角狹窄病人給縮瞳劑後，應在不久後重做 gonioscopy。p.155
  • 具 adrenergic（sympathomimetic）或 anticholinergic（parasympatholytic）活性、可能造成隅角閉鎖的全身藥物⁠Q1276：p.155
    • 過敏與感冒藥：adrenergic agents（如 ephedrine）、antihistamines（如 diphenhydramine）⁠Q1276。p.155
    • 支氣管擴張劑（氣喘與 COPD 用）：ipratropium bromide、tiotropium bromide⁠Q1276。p.155
    • Antidepressants（抗憂鬱藥）、anxiolytics（抗焦慮藥）、antipsychotics（抗精神病藥）：SSRIs（selective serotonin reuptake inhibitors，如 fluoxetine、paroxetine）、tricyclic antidepressants（三環抗憂鬱藥，如 amitriptyline、imipramine）、antihistamine-anxiolytics（如 hydroxyzine）、phenothiazines（如 chlorpromazine）⁠Q1276。p.155
    • Urinary antispasmodics（泌尿道抗痙攣藥）：tolterodine、oxybutynin⁠Q1276。p.155
    • 腸胃藥：antihistamines（如 cimetidine）。p.155
    • Muscle relaxants（肌肉鬆弛劑）：orphenadrine、trihexyphenidyl。p.155
    • Antinauseants（止吐藥）：promethazine⁠Q1276。p.155
  • 全身給藥使眼內藥物濃度上升的程度一般不如局部給藥，但隅角極度狹窄者即使輕微散瞳也可誘發隅角閉鎖；給可能閉鎖隅角的病人使用這類藥物時，應告知風險並考慮 laser peripheral iridotomy（LPI，雷射周邊虹膜切開術）⁠Q1276。p.155
  • Drug-induced secondary angle closure（Chapter 10）：topiramate 在部分病人可造成以急性近視化與急性雙側隅角閉鎖為特徵的症候群，眼部表現包括 choroidal effusion（脈絡膜滲漏）；治療為立即停藥、房水抑制劑，全身類固醇可能加速恢復，積極 cycloplegia（睫狀肌麻痺）可能幫助加深前房；因 pupillary block 不是此症候群的潛在機轉，LPI 不適用⁠Q1167 Q1152 Q1197。BCSC 10 p.183–184

易錯陷阱

  • 易感眼中散瞳劑與縮瞳劑都可能誘發急性隅角閉鎖；強效縮瞳劑可能使 lens–iris interface 前移並增加 pupillary block⁠Q1216。p.154
  • 抗憂鬱藥、止吐藥（promethazine）、泌尿道抗痙攣藥（tolterodine、oxybutynin）都列在可能造成隅角閉鎖的全身藥物中⁠Q1276。p.155
  • Topiramate 誘發的急性近視化與雙側隅角閉鎖症候群（見於部分病人），pupillary block 不是其潛在機轉，因此 LPI 不適用⁠Q1167 Q1152 Q1197。BCSC 10 p.183–184

四、危險因子

Race and ethnicity（種族）

族群（40 歲以上）PACG 盛行率
African ancestry（非洲裔）0.1%–0.6%
European-derived（歐洲裔）0.1%–0.4%
Japanese（日本人）0.3%–2.2%
Chinese（華人）0.4%–1.7%
Inuit（因紐特人）2.1%–4.8%

出處 ⁠Q1182p.155

  • 40 歲以上 PACG 盛行率依種族差異很大；部分差異（如白人與 Inuit 之間）可由生物測量參數（anterior chamber depth（ACD，前房深度）、axial length（眼軸長））差異解釋⁠Q1182。p.155
  • 華人與其他東亞族群 PACG 盛行率較高，無法只用主要生物測量參數解釋；前段解剖研究提示虹膜厚度與面積、虹膜動態變化、lens vault、anterior chamber width（ACW，前房寬度）可能是重要促成因素。p.155
  • Anterior segment optical coherence tomography（AS-OCT，前段光學同調斷層掃描）：與白人相比，華人 ACD 較淺、虹膜較厚、ACW 較小，且由亮處到暗處時虹膜厚度與面積增加。p.155
  • PACG 負擔在亞洲國家較大；但亞洲（尤其都會區）近視盛行率（伴隨眼軸延長）近年上升，可能抵銷此趨勢。p.155–156

Ocular biometrics（眼球生物測量）

  • PACD 眼常有小而「擁擠」的前段與短眼軸。p.156
  • 最重要的易感因素：淺前房、厚水晶體、水晶體前表面曲率增加、短眼軸、小角膜直徑與曲率半徑；前段影像另找出虹膜厚度與面積增加、lens vault 較大等危險因子。p.156
  • ACD <2.5 mm 使病人易發生 PAC；多數 PAC 病人 ACD <2.1 mm。p.156
  • 原發性 PAS 在 ACD >2.4 mm 的眼睛不常見；PAS 增加與 ACD <2.4 mm 有強烈相關。p.156
  • 部分病例的隅角閉鎖發生在深前房眼，原因是 plateau iris。p.156
  • 上述 ACD 門檻指 true ACD（角膜內皮到水晶體囊）；部分儀器（如 IOLMaster）測的是角膜上皮到水晶體囊的距離。p.156

Age（年齡）

  • 隅角閉鎖盛行率在 40 歲後每十年遞增，解釋為水晶體隨年齡增厚、前移，虹膜水晶體接觸增加。p.156
  • PACD 在 40 歲以下罕見；年輕人的隅角閉鎖最常與結構或發育異常有關，如 plateau iris 與 retinopathy of prematurity（ROP，早產兒視網膜病變），而非 pupillary block。p.156

Sex（性別）

  • 不論種族，原發性隅角閉鎖在女性比男性常見 2–4 倍⁠Q1182 Q1203。p.156
  • 生物測量研究發現女性的前段傾向比男性小、眼軸傾向比男性短，但這些差異似乎不足以完全解釋性別傾向。p.156–157
  • Chapter 1：年齡、種族為 PACG 危險因子；PACG 盛行率可能因性別而異，多數研究中女性盛行率顯著較高；遠視與隅角閉鎖家族史也是重要危險因子⁠Q1203 Q1182。BCSC 10 p.16

Family history and genetics（家族史與遺傳）

  • 受影響者的一等親 PAC 盛行率增加：白人一等親 PAC 盛行率報告為 1%–12%；華人調查顯示有任何家族史者風險高 6 倍；Inuit 有家族史者相對風險為一般 Inuit 族群的 3.5 倍⁠Q1182。p.157
  • 家族關聯支持遺傳影響；近期 GWAS（全基因體關聯研究）顯示複雜的遺傳模式，基因位點外顯率不一。p.157

Refractive error（屈光不正）

  • 不論種族，PACD 最常見於 hyperopia（遠視）病人⁠Q1182 Q1203。p.157
  • 但明顯近視、甚至單純近視者也會發生隅角閉鎖，尤其是亞洲人 → 所有青光眼病人不論屈光狀態都應做 gonioscopy（隅角鏡檢查）⁠Q1182 Q1225。p.157
  • 高度近視病人發生隅角閉鎖時，應尋找續發機轉：microspherophakia（球形小晶體）、plateau iris，或 phacomorphic 隅角閉鎖眼中的 nuclear sclerotic cataract（核硬化白內障）。p.157
  • Axial myopia 主要來自後段延長，前段有時仍保有易隅角閉鎖的特性；因此雖然近視與眼軸延長與較低的隅角閉鎖風險相關，近視眼仍可能有一些風險⁠Q1182。p.157
  • Chapter 7：已確診 OAG 者應定期重做 gonioscopy，以監測水晶體變化造成的漸進性隅角閉鎖，尤其是遠視病人⁠Q1225。BCSC 10 p.110

易錯陷阱

  • PACD 最常見於遠視；近視與眼軸延長與較低的隅角閉鎖風險相關，但近視眼（尤其亞洲人）仍可能發生⁠Q1182 Q1203。p.157
  • 原發性隅角閉鎖女性為男性的 2–4 倍（不論種族）；家族史（一等親）與種族（Inuit、亞洲族群）也是危險因子⁠Q1182 Q1203。p.155–157
  • ACD <2.5 mm 易發生 PAC；多數 PAC 的 ACD <2.1 mm；PAS 與 ACD <2.4 mm 強烈相關。p.156
  • 40 歲以下 PACD 罕見，年輕人的隅角閉鎖最常與 plateau iris、ROP 等結構或發育異常有關。p.156

五、Primary angle-closure suspect（PACS）與治療爭議

診斷

  • PACS 只有一小部分會發展成隅角閉鎖疾病（acute PAC、PAC 或 PACG），但這些眼睛有風險。p.157
  • 即使由有經驗的醫師執行，gonioscopy 的預測價值仍相對差。p.157
  • 做 gonioscopy 時要注意檢查光線對 angle recess 的影響：例如裂隙燈光束本身誘發的瞳孔收縮可能打開隅角，使狹窄的 recess 未被察覺。p.157
  • AS-OCT 可用來評估潛在的隅角閉鎖：在暗處與亮處成像時，隅角型態可能有明顯變化（Fig 9-2A 關燈時可見隅角閉鎖，Fig 9-2B 開燈時同一隅角開得多）；Video 9-1 中 UBM 捕捉到此動態變化。p.158–159
  • Provocative tests（激發試驗）如藥物散瞳與 darkroom prone provocative test（DRPPT，暗室俯臥激發試驗）可誘發有限度的隅角閉鎖，曾被嘗試用來預測誰會發生隅角閉鎖並從 iridotomy 獲益。p.159
  • Zhongshan Angle-Closure Prevention（ZAP）研究提示激發試驗（15 分鐘暗室俯臥）不能預測隅角閉鎖發作或青光眼的發生（但散瞳或 DRPPT 後 IOP 上升 >15 mm Hg 者被排除於研究外）；前段影像能否較佳預測 PACD 仍在研究中。p.159

Treatment controversies（治療爭議）

  • PACS 是否做 LPI 仍有爭議⁠Q1177。p.159
  • ZAP trial：PACS 病人隨機一眼接受 LPI、另一眼為對照；兩組進展為 PACG 或急性發作者都很少；治療組轉為 PAC 的風險顯著較低，但多數轉換只是形成 PAS，而無 ocular hypertension（高眼壓）。p.159
  • 整體結果提示預防性 LPI 主要適合高風險 PACS 族群；個別病人須考慮隅角狹窄程度、是否有符合 IOP 升高的症狀（如眼部不適），以及病人在現有證據下的偏好等⁠Q1177。p.159
  • 以下情況應考慮 LPI：狹窄隅角合併 PAS、TM 節段性色素增加、曾有急性隅角閉鎖，或其他危險因子（如強烈家族史，例如一等親）；也應考慮水晶體狀態與白內障手術的潛在益處。p.159–160
  • 大部分或全部隅角已被 PAS 閉鎖的眼睛，是否做 LPI 有爭議：outflow facility 有限，可能因散出的色素與虹膜碎屑而 IOP 明顯上升，部分病例 IOP 對藥物無效而需 filtering surgery（濾過手術）→ 應謹慎，考慮 LPI 以外的替代方式可能較佳⁠Q1740。p.160
  • Laser iridoplasty（雷射虹膜成形術）：有證據顯示在 iridotomy 後可進一步加寬狹窄隅角，但沒有強證據顯示可預防青光眼發生或進展。p.160
  • Clear lens extraction（CLE，透明水晶體摘除）可能對部分隅角閉鎖病人有益。p.160
  • EAGLE study（Effectiveness of Early Lens Extraction for the Treatment of PACG）：前瞻性隨機對照試驗，收案 ≥50 歲、無視力上明顯白內障，且為新診斷 PAC 合併 IOP ≥30 mm Hg 或 PACG；70% 非華人、30% 華人⁠Q1740。p.160
  • EAGLE 結果：CLE 比標準治療（LPI＋藥物）IOP 較低、用藥較少、生活品質較好；視野惡化兩組相似⁠Q1740 Q1159。p.160

PACS 的處置

  • 符合 PACS 標準的眼睛施行 LPI 被認為合理，但並非所有 PACS 病人都需要 iridotomy；是否治療無症狀的狹窄隅角，依隅角的準確評估、醫師臨床判斷與病人偏好而定⁠Q1177。p.161
  • 任何狹窄隅角病人都應被告知急性隅角閉鎖的症狀、出現症狀時需立即就醫，以及長期定期追蹤的價值。p.161

易錯陷阱

  • ZAP：預防性 LPI 降低轉為 PAC 的風險（多數轉換只是 PAS），進展為 PACG 或急性發作在兩組都很少；預防性 LPI 主要適合高風險 PACS⁠Q1177。p.159
  • ZAP 研究結果提示激發試驗（15 分鐘暗室俯臥）不能預測隅角閉鎖發作或青光眼發生（散瞳或 DRPPT 後 IOP 上升 >15 mm Hg 者被排除於研究外）。p.159
  • EAGLE 收案條件是新診斷 PAC 合併 IOP ≥30 mm Hg 或 PACG（≥50 歲、無視力上明顯白內障）；CLE 的 IOP 較低、用藥較少、生活品質較好（相較於以 LPI 為主的標準治療），視野惡化兩組相似⁠Q1740。p.160
  • Laser iridoplasty 可在 iridotomy 後進一步加寬隅角，但沒有強證據可預防青光眼發生或進展。p.160

六、Primary angle closure（PAC）與 Primary angle-closure glaucoma（PACG）

PAC

  • 隅角可逐漸閉鎖，隨隅角功能漸受損而 IOP 緩慢上升；即使沒有粘連性閉鎖，虹膜小樑網接觸也可能損傷 TM 而使 IOP 升高。p.161
  • 慢性 PAC（無症狀的粘連性隅角閉鎖）是 PACD 最常見的表現。p.161
  • 處置：通常需要 LPI 以解除 pupillary block 成分、減少進一步粘連性閉鎖的可能；但大範圍粘連的眼睛做 LPI 有爭議，因可能出現 IOP 上升⁠Q1177 Q1166 Q1740。p.161
  • 沒有 iridotomy 時，隅角閉鎖通常會進展、IOP 更難控制；即使 peripheral iridotomy 通暢，仍可能漸進性閉鎖 → 定期重複 gonioscopy 非常必要。p.161
  • Iridotomy 合併或不合併長期降眼壓藥，可控制多數 PAC 病人；EAGLE 提示 IOP ≥30 mm Hg 的 PAC，clear lens extraction 可能是首選治療⁠Q1740。p.161

PACG

  • 符合 PAC 條件，另有符合青光眼的視神經損傷。p.161
  • 因病程隱匿，視力喪失可能是首發症狀；PACG 是亞洲致盲的主要原因之一，常在晚期才被診斷。p.161–162
  • 臨床病程通常與 open-angle glaucoma 相似：初期無症狀、IOP 中度升高、漸進的青光眼性視神經損傷、特徵性視野缺損 → 常被忽略並與 POAG 混淆；但隨時間 IOP 可能急劇上升、更難控制⁠Q1147 Q1192 Q1225。p.162
  • 所有青光眼病人都應做 gonioscopic examination 以正確診斷⁠Q1225。p.162
  • 處置：LPI 被視為 PACG 的標準治療；但與 PAC 相同，大範圍粘連的 PACG 眼做 LPI 可能出現反常性 IOP 上升（paradoxical rise）⁠Q1177 Q1740。p.162
  • 藥物：可包括 aqueous suppressants（房水抑制劑）與 outflow drugs（增加外流藥）；prostaglandin analogues（前列腺素類似物）對 ACG 降壓非常有效，效果相當於或超過 β-blockers；IOP 降幅似乎與永久性隅角閉鎖的範圍無關。p.162
  • 單獨白內障手術即有益於降低 IOP 與用藥，且與白內障摘除合併 trabeculectomy（小樑切除術）相比表現良好（compares favorably）；EAGLE 顯示 lens extraction 可為治療 PACG 的有效選項⁠Q1159 Q1740。p.162

易錯陷阱

  • 慢性 PAC（無症狀粘連性閉鎖）是 PACD 最常見的表現；PACG 臨床病程通常類似 OAG，常被忽略並與 POAG 混淆⁠Q1225。p.161–162
  • 大範圍 PAS 的 PAC／PACG 眼做 LPI 可能出現 IOP 上升（反常性上升），應謹慎；360° 粘連性閉鎖無法從 iridotomy 獲益⁠Q1740。p.160–162；BCSC 10 p.255
  • PACG 中前列腺素類似物效果相當於或超過 β-blockers，降幅似乎與永久性閉鎖範圍無關。p.162
  • 即使 iridotomy 通暢仍可能漸進性閉鎖，需定期 gonioscopy。p.161

七、Symptomatic primary angle closure（有症狀的原發性隅角閉鎖）

  • IOP 升高合併隅角大部分急性或亞急性阻塞，可造成有症狀的隅角閉鎖。p.162

Subacute primary angle closure（亞急性／間歇性）

  • IOP 升高造成反覆發作的視力模糊、halos（光暈）、輕度疼痛；無視覺症狀的模糊疼痛或頭痛，對隅角閉鎖的特異性低。p.162
  • 視覺症狀會自行緩解，尤其是睡眠時的縮瞳；發作之間 IOP 通常正常，發作可週期性出現數天、數月或數年。p.162
  • 常被誤認為頭痛或偏頭痛，需仔細問病史；只有高度懷疑並做 gonioscopy 才能正確診斷（典型病史＋狹窄隅角，有或無 PAS）；處置與 PAC 相似。p.162

Acute primary angle closure（APAC，急性原發性隅角閉鎖）：表現與診斷

  • APAC（有時稱 acute angle-closure crisis）：虹膜相對突然阻塞 TM → IOP 迅速上升⁠Q1147 Q1192。p.162
  • 症狀：典型為眼痛、頭痛、視力模糊、燈光周圍光暈；急性全身不適可能造成噁心、嘔吐⁠Q1147 Q1192。p.163
  • 徵象：IOP 高；中度散大、反應遲緩、形狀不規則的瞳孔；角膜上皮水腫；上鞏膜與結膜血管充血；周邊前房淺；少量 aqueous flare 與 cells。p.163
  • IOP 升到相對高的程度造成角膜上皮水腫，這是視覺症狀的原因。p.163
  • 確診有賴 gonioscopy 證實隅角閉鎖；幾乎所有 APAC 都可做 gonioscopy，但可能需要局部降眼壓治療、topical glycerin（局部甘油）或 paracentesis（前房穿刺）先清除角膜水腫。p.163
  • Dynamic gonioscopy（壓迫中央角膜）可幫助判斷阻塞是可逆（貼合性）或不可逆（粘連性），也可能有治療作用，打斷急性發作⁠Q1740。p.163
  • APAC 病人的對側眼 gonioscopy 通常為狹窄、可閉鎖的隅角；對側眼若隅角深，應尋找 IOP 升高的續發原因：後段腫塊、zonular insufficiency（懸韌帶不全）、前段新生血管、iridocorneal endothelial（ICE）syndrome。p.163
  • 裂隙燈光束可造成瞳孔收縮，人為打開原本狹窄的隅角；gonioscopy 有主觀、依技術而異的成分，應盡量減少造成變異的因素。p.163
  • 急性發作時 IOP 可能高到造成青光眼性視神經損傷、ischemic optic neuropathy（缺血性視神經病變）及／或 retinal vascular occlusion（視網膜血管阻塞）。p.163
  • PAS 可快速形成；IOP 引起的缺血可造成虹膜扇形萎縮、釋出色素 → 虹膜表面與角膜內皮色素沉著；虹膜括約肌缺血可使瞳孔永久固定散大。p.163
  • Glaukomflecken：因壞死形成的特徵性小型 anterior subcapsular（前囊下）水晶體混濁；這些發現有時有助於發現過去的 APAC 發作。p.163

APAC 的處置

  • 與 pupillary block 相關的 APAC，definitive treatment（確定治療）通常是 LPI：iridotomy 後 pupillary block 解除、前後房壓力差正常化，多數病例虹膜離開 TM，前房加深、隅角打開⁠Q1257 Q1263 Q1739。p.163
  • 就診時的角膜水腫可能妨礙做出通暢的 LPI，可能需要藥物或處置先打斷發作、清除角膜水腫，再做 iridotomy⁠Q1257。p.163
  • APAC 若輕微，可用 cholinergic agents（pilocarpine 1%–2%）縮瞳，把周邊虹膜拉離 TM；但這類藥可能使某些無 pupillary block 的隅角閉鎖惡化，也可能在部分眼睛加重 pupillary block⁠Q1257。p.164
  • 較強效的縮瞳劑最好避免：可能增加虹膜血管充血，或使 lens–iris interface 更向前旋轉而增加 pupillary block⁠Q1257。p.164
  • IOP 顯著升高（如 >40–50 mm Hg）時，瞳孔括約肌可能缺血，單用縮瞳劑無反應 → 因此多數病例改用其他局部藥：β-adrenergic antagonists（β 阻斷劑）、α2-adrenergic agonists（α2 致效劑）、prostaglandin analogues，以及局部、口服或靜脈 carbonic anhydrase inhibitors（CAI，碳酸酐酶抑制劑）；必要時口服或靜脈給 hyperosmotic agents（高滲透壓劑）⁠Q1257。p.164
  • 應避免非選擇性 adrenergic agonists 或有明顯 α1 活性的藥物（如 apraclonidine），以免瞳孔進一步散大與虹膜缺血⁠Q1167。p.164
  • 快速降 IOP 以清除角膜水腫的技巧：壓迫中央角膜的 globe compression、dynamic gonioscopy、以 30-gauge 針或銳刀小心做 paracentesis；淺前房眼做這些操作容易傷及水晶體或虹膜，須小心⁠Q1257。p.164
  • 發作打斷、角膜夠清澈後，通常施行 LPI；lens extraction（水晶體摘除）也是可行的選項，但急性期（尤其眼睛發炎時）LPI 可能較容易完成；laser iridoplasty 是另一選項；罕見情況需要 surgical iridectomy（手術虹膜切除）⁠Q1257。p.164
  • 急性發作緩解後，重要的是以 gonioscopy 重新評估隅角，評估殘餘粘連性閉鎖程度，並確認至少部分隅角重新打開。p.164
  • IOP 改善不一定代表隅角已打開：睫狀體缺血、房水生成減少，可使急性隅角閉鎖後 IOP 偏低達數週 → IOP 可能不是隅角功能或型態的好指標，第二次或連續 gonioscopy 是追蹤所必需。p.164
  • 多數 APAC 的對側眼有相同的解剖易感性，發生同樣狀況的風險高，尤其誘發機轉包括全身擬交感藥（如鼻塞藥）或抗膽鹼藥時；若對側眼隅角型態相似，建議對側眼做 LPI。p.164

易錯陷阱

  • APAC 若輕微，可能以 pilocarpine 1%–2% 打斷；較強效縮瞳劑最好避免；IOP 顯著升高（如 >40–50 mm Hg）時括約肌可能缺血、單用縮瞳劑無反應⁠Q1257。p.164
  • 與 pupillary block 相關的 APAC，確定治療通常為 LPI；發作打斷後 lens extraction 與 laser iridoplasty 也是選項⁠Q1257 Q1263。p.163–164
  • APAC 應避免非選擇性 adrenergic agonists 與 α1 活性明顯的藥（如 apraclonidine）⁠Q1167。p.164
  • 急性發作後 IOP 可能因睫狀體缺血與房水生成減少而偏低達數週；IOP 改善不一定代表隅角已打開，IOP 可能不是隅角功能或型態的好指標，追蹤須做第二次或連續 gonioscopy。p.164
  • APAC 對側眼隅角深 → 找續發原因（後段腫塊、懸韌帶不全、前段新生血管、ICE syndrome）。p.163
  • Glaukomflecken 是因壞死形成的小型前囊下水晶體混濁；它與虹膜扇形萎縮、色素沉著、永久固定散大的瞳孔等發現，有時有助於發現過去的 APAC 發作。p.163

八、Plateau iris（高原虹膜）

定義與診斷

  • Plateau iris 是前房隅角的非典型型態，可能導致 PACD；是年輕隅角閉鎖病人的常見發現。p.164
  • 證據提示此型態來自前位的 ciliary processes（UBM 上表現為 ciliary sulcus（睫狀溝）消失），或虹膜在睫狀體上的附著點偏前⁠Q1286。p.164
  • 懷疑 plateau iris：在隅角閉鎖的眼睛，中央前房深度看似正常、虹膜平面看似平坦⁠Q1286。p.165
  • 確認：dynamic gonioscopy 出現 "double-hump" sign（雙峰徵） —— 前位睫狀突把虹膜頂住，虹膜輪廓出現一個峰（"peripheral roll"，周邊捲起）；Fig 9-3A：pupillary block 眼的壓迫隅角鏡檢查可見單一峰（虹膜環狀覆蓋於水晶體前囊），隅角因前房壓力增加而較深⁠Q1286。p.165
  • 只靠裂隙燈檢查或 Van Herick 法會漏診⁠Q1286。p.165
  • Plateau iris configuration（高原虹膜型態）：因睫狀體前位而隅角狹窄，中央前房深⁠Q1286。p.165
  • Plateau iris syndrome（高原虹膜症候群）：因睫狀體前位而隅角狹窄、中央前房深，且LPI 通暢後仍持續有 iridotrabecular contact；此症候群眼的藥物散瞳可能誘發 IOP 上升 6 mm Hg 以上⁠Q1286 Q1739。p.165
  • PAS 形成方向：plateau iris 報告為從 Schwalbe line 開始，再向後延伸越過 TM、scleral spur 與 angle recess；pupillary block 引起的隅角閉鎖則相反，粘連由後往前形成。p.165–166
  • Fig 9-3C：一隻 plateau iris configuration 眼的 UBM 顯示周邊虹膜接觸 Schwalbe line，位於 angle recess 前方。p.165

機轉

  • Plateau iris 眼的隅角閉鎖最常由前位睫狀突把周邊虹膜向前推，嚴重窄化 angle recess 所致；也可能存在 pupillary block 成分⁠Q1739 Q1286。p.166
  • 瞳孔散大後周邊虹膜擠向並阻塞 TM，隅角可能進一步受損。p.166
  • 隅角狹窄或閉鎖的原因從單純 pupillary block 到以 plateau iris 為主不等，常是兩者合併⁠Q1739。p.166

處置

  • Plateau iris 的初步處置：LPI 以去除任何 pupillary block 成分，或有白內障時做 lens extraction⁠Q1152 Q1197 Q1166。p.166
  • Plateau iris configuration 的眼睛可以只追蹤、不再介入。p.166
  • 因周邊虹膜解剖，plateau iris syndrome 眼即使 iridotomy 通暢仍易隅角閉鎖，甚至可能急性發作；plateau iris syndrome 是 LPI 或白內障手術後隅角持續狹窄或可閉鎖的最常見原因 → LPI 或 lens extraction 後須仔細評估隅角，決定是否需要進一步加深隅角的治療⁠Q1739。p.166
  • Plateau iris syndrome 可用長期縮瞳劑治療；但laser iridoplasty 可能更有用，可使周邊虹膜變平、變薄。p.166
  • 即使採取加深 angle recess 的措施，慢性隅角閉鎖風險仍在 → 須定期重複 gonioscopy；plateau iris syndrome 的處置仍在演進，最佳處置需更多研究。p.166

易錯陷阱

  • 隅角閉鎖眼中央前房深度看似正常、虹膜平面看似平坦時懷疑 plateau iris；plateau iris configuration 指睫狀體前位造成隅角狹窄、中央前房深；UBM 上睫狀溝消失⁠Q1286。p.164–165
  • Plateau iris syndrome 的定義是 LPI 通暢後仍持續 iridotrabecular contact；plateau iris 眼的隅角閉鎖最常由前位睫狀突把周邊虹膜向前推所致，也可能有 pupillary block 成分⁠Q1286 Q1739。p.165–166
  • Plateau iris 的初步處置為 LPI（去除 pupillary block 成分）或有白內障時 lens extraction⁠Q1152 Q1197 Q1166。p.166
  • 只靠裂隙燈或 Van Herick 法會漏診 plateau iris；以 dynamic gonioscopy 的 double-hump sign 確認⁠Q1286。p.165
  • Phacomorphic glaucoma 屬續發性（膨脹水晶體）隅角閉鎖，pupillary block 常扮演重要角色；suprachoroidal 或 supraciliary effusion 的質量效應可能使 lens–iris interface 前移，造成續發性隅角閉鎖⁠Q1267 Q1739。p.151；BCSC 10 p.168, p.181
