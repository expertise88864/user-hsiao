# 第三輪：首次造訪與快取版本

日期：2026-10-07。本文件描述這批工程範圍；正式交付須另外核對最終 SHA、CI、Preview、部署及 smoke。

## 問題與原因

首頁、文章索引、部分研究文章及後台的版本守衛，原本只要瀏覽器支援 Service Worker 或 Cache Storage，就在版本標記不符時清理並重載。全新讀者沒有舊 worker 或快取，也會重載。

正式版本 `916f177` 的 Windows Chrome 手機受控測試，以全新儲存狀態對比僅預先寫入目前版本標記的情境，每組三次。首頁與索引多出重載及部分請求中止；沒有此守衛的乾眼文章沒有重載差異。版本標記對照只用於隔離原因，不是產品修改。

本批守衛仍讀取並清理註冊與快取。存在 worker、控制中的 worker、快取，或無法檢查時，保留原本的一次重載。確認沒有舊狀態時，只記錄版本，不重載。版本無法保存時不進入重載迴圈。

各項檢查、worker 解除註冊及快取刪除分別等待成功或失敗；其中一項失敗不能使其他尚未完成的清理被重載中斷。失敗仍走保守重載，不宣稱瀏覽器拒絕的清理已成功。

## 驗證與限制

- 新訪客、舊 worker／快取、控制中的 worker、檢查失敗、版本已一致及不支援 API 六組邏輯回歸，加上三組一項失敗、另一項延後完成的順序回歸。
- 實際中英文首頁與索引空快取只請求一份文件；舊離線快取先刪除再重載一次。保留既有延後載入的索引節點、分類、鍵盤、無 JS 與 200% 放大回歸。
- 編輯器延後初始化及連續八次保存／重開，同時驗證全新儲存只開啟一次，以及真正舊快取清除後重載一次；保留保存內容、請求期間新輸入與斷線同步的原驗收。
- 相同 Windows Chrome、390px、4 倍 CPU 減速、150ms 延遲與 200KB/s 下載，在本機相同服務環境各做三次修正前後比較。保留所有樣本與中止請求，不只挑選最快值。
- 靜態資源版本與 `hs:siteVer` 同步更新；英文頁、min.js 與 CSP 雜湊透過既有權威生成器產生。CSP、字型策略、內容、URL 與統計定義沒有因此放寬。
- 作者 HTML 文字對照只排除既有快取守衛、宣告的靜態資源版本及行尾／檔末換行；正文、摘要、雙語文字與引用保持相同。

本機比較使用 HTTP 靜態來源，不能代替正式 middleware、Ubuntu 視覺、正式訪客 CWV、Google 排名或點閱率。此修正只處理已證明的多餘重載；P-07 的全站 LCP／CLS 與混合版本、裝置、低 INP 樣本限制仍需追蹤。

## 候選 CI 發現的 A/B 請求競態

候選瀏覽器測試偶發發現，預先載入頁面啟用及稍後的讀者初始化會重複取得 A/B 設定。延後回應的實際函式回歸確認三次呼叫產生三次請求；請求期間切入編輯模式也會套用已收到的實驗內容。

同一份文件現在共用成功的設定請求，設定失敗仍允許下一次重試；套用前再確認編輯模式。既有元素標記、曝光與轉換定義、隱私排除及變體設定不變。回歸保留原始失败與修正後結果，這不是正式訪客統計改善的證據。
