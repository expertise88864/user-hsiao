# 寫作工作區與圖片描述 — 2026-10-08

這批延續現有編輯器，只處理兩項測試情境中的障礙：文章資訊預設佔滿寫作空間，以及一般圖片缺少直接修改替代文字的操作。未進行站主人類完成時間研究；不能把 fixture 回歸當作正式 CMS 實寫。

## 寫作操作

文章標題與搜尋摘要預設收合，可用工具列「文章資訊」或原生收合標題開啟。鍵盤 Tab、Enter／Space 保留；欄位檢查失敗會展開並聚焦。聚焦欄位避開底部固定工具列。開啟／收合不算作者修改。

「圖片替代文字」列出目前語言中可見的正文一般圖片。描述圖片在文中的用途；純裝飾且不傳達資訊的圖片可以留空。SVG 圖表與可直接編輯的圖說維持原有方式。

- 「套用替代文字」才將輸入納入 Undo／Redo、草稿及後續保存；「取消」或 Escape 放棄本視窗輸入。
- 輸入尚未套用時，切換圖片會保留文字並提示先套用或取消；保存與離開也會提示，不默默丟失输入。
- 圖片被移除或閱讀語言已改變時不套用至另一個目標，保留視窗輸入供複製後重新操作。
- 圖片來源、picture／srcset、圖說、作者自訂屬性及特殊區塊保留。編輯視窗與工作區不進作者 HTML。

## 保存與上線

本機草稿、本機預覽、公開 Git 保存、候選 Preview 與正式上線是不同狀態。視窗未套用的文字尚未進草稿；Git 保存成功仍須 exact-SHA 候選驗證與正式發佈。公開分支及 noindex 都不等於私人草稿。

原有中文 IME、貼上、雙語、Undo／Redo、斷線恢復、多分頁與 stale baseSha 保護仍適用。不能為驗收而寫入正式文章、覆寫 CMS 新修改或製造正式讀者事件。

## 驗收與界線

本機情境涵蓋 360／390／768／1440px、鍵盤收合與視窗操作、合成 composition 事件、圖片文字套用／取消／復原、雙語保存再讀取與作者 HTML 保留。合成事件不是作業系統 IME 實際輸入研究。

CI 額外在 exact-SHA Preview 取得新工作區畫面：使用公開文章的隔離範例來源，所有非 GET／HEAD 請求中止，其他管理 API 讀取以 fixture 阻隔；不使用管理員登入或讀取私人統計。畫面是 Ubuntu 的新覆蓋，必須另由站主確認；不自動更新 27 張公開閱讀基準。

每個修改、生成物、文件及 audit 仍按 D-20／D-28 完成獨立完整審查、候選 CI／Preview／適用人工視覺確認與正式 CI／部署／smoke。這份操作說明本身不宣稱承載它的新 SHA 已交付。
