隱私權政策

最後更新：2026 年 10 月 7 日

歡迎使用 HsiaoEye（以下簡稱「本網站」）。本政策說明網站的資料處理、分析工具、瀏覽器儲存與退出方式。

1. 我們收集哪些資訊

1-1 您主動提供的資訊

閱讀本網站不需要註冊。網站不要求讀者提供姓名、身分證、病歷、症狀描述、照片或聯絡方式；亦不提供掛號服務。請勿在站內搜尋輸入這些資料。

1-2 伺服器日誌與錯誤診斷

網站由 Vercel 託管。網路請求、安全防護與錯誤診斷可能處理 IP 位址、瀏覽器、作業系統、頁面網址、來源網站及時間。這些日誌與下方第一方效能樣本不同，不能一概稱為匿名資料。

符合收件條件的瀏覽器錯誤回報包含錯誤訊息、堆疊、網址、瀏覽器及 IP，可能記錄於部署日誌；設定 KV 儲存時另保留最多 200 筆。預覽、編輯、自動化及已退出的瀏覽器診斷會排除，但必要的伺服器安全日誌仍可能保留。

1-3 Cookie 與瀏覽器儲存

hs_lang Cookie 記錄語言偏好，有效期 365 天。localStorage 可記錄語言、主題、字型大小、閱讀位置與快取版本；瀏覽器快取可保留離線頁面。管理者本機草稿另使用瀏覽器儲存，不屬於一般讀者統計。

hs_telemetry_optout=1 是量測退出偏好，不是登入憑證或訪客識別碼。管理者登入時會設定此偏好以排除管理操作，登出不會自動取消退出。管理者登入另有 8 小時的 HttpOnly 工作階段 Cookie。

1-4 第一方效能與實驗統計

網站可將 Web Vitals 效能數值、頁面路徑、時間、量測版本及樣本 ID 傳送至自有收件端。設定 KV 時，每個指標最多保留 1,000 筆，儲存清單設有 30 天到期時間；樣本 ID 用於去重，不等於不重複訪客人數。

內容實驗能力可記錄實驗與版本的曝光及點擊計數，瀏覽器可能保存版本分派。是否有啟用中的實驗與實際收件，取決於設定；程式具備能力不代表每項功能都已啟用。

站內搜尋記錄預設關閉，只有設定 SEARCH_LOG_ENABLED=1 且儲存可用時才保存最多 1,000 筆、最長 80 字的搜尋詞及時間，用於內容缺口分析。請勿輸入個人或醫療敏感資料。

2. 第三方服務

2-1 Google Analytics 4

符合一般讀者收件條件時，網站載入 Google Analytics 4（評估 ID：G-0ZKDQP9DNH），記錄頁面及互動事件。Consent Mode v2 的預設組態允許 analytics_storage、functionality_storage、security_storage；ad_storage、ad_user_data、ad_personalization 則拒絕。這是技術組態，不等於使用者已明確同意。本站不投放個人化廣告。

GA4 使用第一方 _ga（區分使用者）與 _ga_<ID>（維持工作階段狀態）Cookie，Google 文件列出的預設期限為 2 年，實際期限可依設定不同。它們是分析識別資訊，不能說完全沒有 Cookie 或完全無法識別。

Google 文件：GA4 Cookie 使用；Google 隱私權政策。Microsoft Clarity 目前未啟用，未來若啟用會更新本頁。

2-2 Vercel Web Analytics 與 Speed Insights

網站在符合收件條件時載入這兩項服務。Web Analytics 用於頁面浏览統計，Speed Insights 用於頁面效能量測；實際是否保存取決於 Vercel 專案設定。服務文件說明 Web Analytics 不使用 Cookie，Speed Insights 的效能点不關聯個人訪客或 IP；這不代表平台的安全與請求日誌也不處理 IP。

服務文件：Web Analytics 隱私說明；Speed Insights 隱私說明。

2-3 Google Search Console / Bing Webmaster

用於確認網站所有權、提交 sitemap 及查看搜尋引擎提供的搜尋成效報告，不是本網站額外安裝的逐次訪客追蹤程式。

2-4 字型及外部資源

字型由 Google Fonts 載入，CSS 由自有網域的 /assets/app.css 提供。部分工具可能載入外部程式模組；連線時服務提供者可處理 IP 與請求資訊。

3. 量測退出與瀏覽器控制

一般讀者量測會排除預覽、管理操作、可辨識的自動化、DNT／Global Privacy Control 及本站退出偏好。您也可安裝 Google Analytics 退出外掛。僅封鎖第三方 Cookie 不一定阻止第一方分析 Cookie。

清除 Cookie、localStorage 或離線快取會移除該瀏覽器的偏好與本機資料，也可能移除退出偏好；這不會刪除已傳送到伺服器或第三方的資料。保留退出偏好，或使用瀏覽器的 DNT／Global Privacy Control，可持續表達量測退出選擇。

4. 您的權利

如您希望了解、查詢、更正、刪除或停止處理與您有關的資料，請透過下方聯絡方式提出。適用權利與可識別的資料依相關法規及服務的資料處理方式而定；清除瀏覽器資料不是伺服器刪除請求。

5. 兒童隱私

本網站內容適合一般成人閱讀，不主動要求 13 歲以下兒童提供個人資料。如監護人認為兒童資料可能被誤收，請透過下方聯絡方式告知。

6. 政策更新

本政策可能隨服務與技術變化更新，重大變動會於本頁公告。

7. 聯絡我們

如有隱私或資料處理疑問，請透過 聯絡 Email 提出；請勿寄送密碼、信用卡或不必要的醫療敏感資料。
